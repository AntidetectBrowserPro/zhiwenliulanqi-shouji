# 指纹浏览器手机版下载指南

临时在手机上接班，**「指纹浏览器」** 的环境卡片能帮你先确认当前选中的是哪家店，再打开网页订单后台。Android、iPhone 和鸿蒙设备的安装入口各不相同；如果业务只在原生 App 内开放，还要在对应 App 里完成。

## 先按手头的系统找入口

| 系统 | 指纹浏览器官网列出的入口 | 安装前看什么 |
| --- | --- | --- |
| Android | ARM64 APK | 设备架构、系统安装提示、下载来源 |
| iOS | iPhone 的 App Store 页面 | 当前商店地区、系统版本和兼容机型 |
| 鸿蒙 | 华为应用市场页面 | 当前设备能否安装、商店所列适配情况 |

三个入口列在同一下载页。给同事发安装说明时，写明系统和商店地区比只给一个通用下载按钮更准确。[官网下载页](https://zwbrowser.com/download/)

## 用两个测试身份检查手机值班流程

1. 在首页分别建立「店铺 A」和「店铺 B」环境，名称开头放店名。
2. 选择 A 的卡片，确认标有「当前」，再从首页搜索框打开后台，使用 A 的测试账号登录。
3. 切到 B，用 B 的测试账号打开同一地址。回到 A 时，核对页面上的店铺名。
4. 锁屏后重新打开应用，再检查当前卡片和网页状态。这一步最接近日常临时接班。

![手机首页的当前环境和搜索框](https://zwbrowser.com/images/mobile-guide-active-light.webp)

首页卡片能确认浏览器选中的环境，网站页面上的账号名称能确认实际登录身份。两个一起核对，就能区分「点错了卡片」与「网站要求重新登录」。[手机端打开网页教程](https://zwbrowser.com/help/mobile/start/)
